# Week 10 Mixed Exercises

## Vocabulary

1. Write the German for **the sun** (include article for nouns).
2. Write the German for **the rain** (include article for nouns).
3. Write the German for **the wind** (include article for nouns).
4. Write the German for **the snow** (include article for nouns).
5. Write the German for **the thunderstorm** (include article for nouns).
6. Write the German for **the cloud** (include article for nouns).
7. Write the German for **the weather** (include article for nouns).
8. Write the German for **the fog / mist** (include article for nouns).

## Grammar

1. Write a correct statement using the week's first grammar topic.
2. Change it into a question where possible.
3. Write a negative version using *nicht* or *kein*.
4. Write one sentence beginning with a time or place expression (Position 1).
5. Correct the word order: `Morgen ich fahre nach Berlin.`

## Translation

Translate into German using only familiar A1 structures:

1. Where is the nearest train station / pharmacy?
2. I would like to buy a ticket, please.
3. Go straight ahead and turn right at the traffic lights.
4. I have to work today, but tomorrow I can visit you.
5. Write one personal sentence connected to Week 10.

## Integrated Output

Complete one 60-second speaking response and one 50-word writing response for this milestone:

> Describe weather conditions, talk about seasons and free-time plans, and use modal verbs with correct sentence brackets.
