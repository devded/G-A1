# Week 11 Mixed Exercises

## Vocabulary

1. Write the German for **the head** (include article for nouns).
2. Write the German for **the arm** (include article for nouns).
3. Write the German for **the leg** (include article for nouns).
4. Write the German for **the stomach / belly** (include article for nouns).
5. Write the German for **the back** (include article for nouns).
6. Write the German for **the heart** (include article for nouns).
7. Write the German for **the throat / neck** (include article for nouns).
8. Write the German for **the tooth** (include article for nouns).

## Grammar

1. Write a correct statement using the week's first grammar topic.
2. Change it into a question where possible.
3. Write a negative version using *nicht* or *kein*.
4. Write one sentence beginning with a time or place expression (Position 1).
5. Correct the word order: `Morgen ich fahre nach Berlin.`

## Translation

Translate into German using only familiar A1 structures:

1. Where is the nearest train station / pharmacy?
2. I would like to buy a ticket, please.
3. Go straight ahead and turn right at the traffic lights.
4. I have to work today, but tomorrow I can visit you.
5. Write one personal sentence connected to Week 11.

## Integrated Output

Complete one 60-second speaking response and one 50-word writing response for this milestone:

> Describe health symptoms, make doctor appointments, understand pharmacy instructions, and express past events using the Perfekt tense.
