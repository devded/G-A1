# Week 11 Exercise Answers and Evaluation

## Vocabulary Recall

1. `der Kopf` — the head / মাথা
2. `der Arm` — the arm / হাত (বাহু)
3. `das Bein` — the leg / পা
4. `der Bauch` — the stomach / belly / পেট
5. `der Rücken` — the back / পিঠ
6. `das Herz` — the heart / হৃদয় / হার্ট
7. `der Hals` — the throat / neck / গলা / ঘাড়
8. `der Zahn` — the tooth / দাঁত
9. `die Hand` — the hand / হাত (কবজি থেকে আঙুল)
10. `der Fuß` — the foot / পায়ের পাতা
11. `das Auge` — the eye / চোখ
12. `das Ohr` — the ear / কান

## Open-Task Evaluation Criteria

A valid A1 response must:
- communicate the requested factual points clearly,
- use taught A1 grammatical structures accurately,
- maintain the finite verb in Position 2 (or Position 1 for questions/imperatives),
- capitalise all nouns and the formal pronoun *Sie*,
- use appropriate word choices for the topic **Health & Present Perfect Tense**.
