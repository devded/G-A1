# Week 12 Exercise Answers and Evaluation

## Vocabulary Recall

1. `die Prüfung` — the exam / examination / পরীক্ষা
2. `das Zertifikat` — the certificate / সার্টিফিকেট / সনদপত্র
3. `der Teil` — the part / section / অংশ / ভাগ
4. `die Aufgabe` — the task / exercise / কাজ / প্রশ্ন
5. `die Frage` — the question / প্রশ্ন
6. `die Antwort` — the answer / উত্তর
7. `richtig` — correct / right / true / সঠিক
8. `falsch` — wrong / false / ভুল / মিথ্যা
9. `ankreuzen` — to tick / check a box / চিহ্নিত করা / টিক দেওয়া
10. `ausfüllen` — to fill out / complete / পূরণ করা (ফরম)
11. `das Formular` — the form / ফরম
12. `der Text` — the text / পাঠ্য / অনুচ্ছেদ

## Open-Task Evaluation Criteria

A valid A1 response must:
- communicate the requested factual points clearly,
- use taught A1 grammatical structures accurately,
- maintain the finite verb in Position 2 (or Position 1 for questions/imperatives),
- capitalise all nouns and the formal pronoun *Sie*,
- use appropriate word choices for the topic **Goethe A1 Exam Prep & Mock Exams**.
