# Week 9 Exercise Answers and Evaluation

## Vocabulary Recall

1. `der Bahnhof` — the train station / রেল স্টেশন
2. `die Post` — the post office / ডাকঘর
3. `die Bank` — the bank / ব্যাংক
4. `das Krankenhaus` — the hospital / হাসপাতাল
5. `die Apotheke` — the pharmacy / ফার্মেসি / ওষুধের দোকান
6. `das Rathaus` — the town hall / সিটি হল
7. `der Supermarkt` — the supermarket / সুপারমার্কেট
8. `das Museum` — the museum / জাদুঘর
9. `geradeaus` — straight ahead / সোজা এগিয়ে
10. `links abbiegen` — turn left / বামে মোড় নিন
11. `rechts abbiegen` — turn right / ডানে মোড় নিন
12. `die Kreuzung` — the junction / intersection / চৌরাস্তা / মোড়

## Grammar & Word Order Solutions

1. `Gehen Sie geradeaus und biegen Sie an der Kreuzung rechts ab.`
2. `Der Zug nach Berlin fährt um 10:15 Uhr von Gleis 3 ab.`
3. `Ich muss heute arbeiten, deshalb kann ich nicht kommen.`
4. `Gestern habe ich zwei Stunden Deutsch gelernt.`
5. `Wo ist die nächste Haltestelle?`

## Open-Task Evaluation Criteria

A valid A1 response must:
- communicate the requested factual points clearly,
- use taught A1 grammatical structures accurately,
- maintain the finite verb in Position 2 (or Position 1 for questions/imperatives),
- capitalise all nouns and the formal pronoun *Sie*,
- use appropriate word choices for the topic **City, Transport & Directions**.
