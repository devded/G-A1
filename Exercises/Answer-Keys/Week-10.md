# Week 10 Exercise Answers and Evaluation

## Vocabulary Recall

1. `die Sonne` — the sun / সূর্য
2. `der Regen` — the rain / বৃষ্টি
3. `der Wind` — the wind / বাতাস / বায়ু
4. `der Schnee` — the snow / তুষার / বরফ
5. `das Gewitter` — the thunderstorm / বজ্রঝড়
6. `die Wolke` — the cloud / মেঘ
7. `das Wetter` — the weather / আবহাওয়া
8. `der Nebel` — the fog / mist / কুয়াশা
9. `bewölkt` — cloudy / overcast / মেঘলা
10. `sonnig` — sunny / রৌদ্রোজ্জ্বল
11. `windig` — windy / ঝড়ো / বাতাসযুক্ত
12. `kalt` — cold / ঠান্ডা

## Open-Task Evaluation Criteria

A valid A1 response must:
- communicate the requested factual points clearly,
- use taught A1 grammatical structures accurately,
- maintain the finite verb in Position 2 (or Position 1 for questions/imperatives),
- capitalise all nouns and the formal pronoun *Sie*,
- use appropriate word choices for the topic **Weather, Seasons & Modal Verbs**.
