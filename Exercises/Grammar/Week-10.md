# Week 10 Grammar Drills

## A. Build Statements

Use each pattern with your own true information:

1. `Entschuldigung, wie komme ich zu/zur …?`
2. `Ich möchte gerne …`
3. `Am Wochenende kann/muss/will ich …`
4. `Es ist heute sehr …`
5. `Gestern habe ich …`
6. `Können Sie mir bitte sagen, wo … ist?`

## B. Word Order Practice

Reorder the scrambled words into grammatically correct sentences:

1. zum Bahnhof / wie / ich / komme / ?
2. fährt / um 14 Uhr / der Zug / ab / .
3. nicht / heute / kann / kommen / er / .
4. sehr / heute / es / kalt / ist / .
5. Deutsch / gestern / zwei Stunden / gelernt / habe / ich / .

## C. Sentence Transformation

1. Turn a declarative statement into a yes/no question.
2. Make a statement negative using *nicht* or *kein*.
3. Begin a statement with a time adverb (inversion: Verb on Position 2).
4. Change the subject from *ich* to *wir*.
5. Convert a present tense sentence into the Perfekt past tense.
